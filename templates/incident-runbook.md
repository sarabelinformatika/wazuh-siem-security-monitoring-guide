# Wazuh Platform and Detection Incident Runbook

## Triage

Record incident ID, affected components and agents, business impact, start time, detection gap, data sensitivity, trusted communications, and incident commander.

## Actions

1. Preserve platform, endpoint, identity, and network evidence.
2. Determine whether the event is a security incident, platform failure, or both.
3. Contain through an approved path without destroying required evidence.
4. Check adjacent components, credentials, certificates, backups, and integrations.
5. Restore from known-good state when integrity cannot be established.
6. Validate ingestion, detections, notifications, access, and recovery before return.
