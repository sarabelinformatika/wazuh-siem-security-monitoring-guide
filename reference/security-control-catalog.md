# Security Control Catalogue

| ID | Objective | Minimum evidence | Review |
|---|---|---|---|
| WZ-01 | Supported and inventoried deployment | Versions, topology, lifecycle, owners | Monthly |
| WZ-02 | Trusted component identity | PKI inventory, expiry, denied TLS tests | Monthly |
| WZ-03 | Controlled agents and sources | Asset reconciliation, groups, validation events | Weekly |
| WZ-04 | Governed detection content | Catalogue, review, logtest fixtures, change history | Quarterly |
| WZ-05 | Least-privilege administration | RBAC matrix, MFA, allow/deny tests | Monthly |
| WZ-06 | Reliable evidence pipeline | Ingestion delay, queues, source failure alerts | Daily |
| WZ-07 | Managed storage and retention | Lifecycle, capacity, snapshot and deletion evidence | Monthly |
| WZ-08 | Safe response automation | Approval, scope, rollback and execution audit | Quarterly |
| WZ-09 | Independent platform monitoring | Synthetic health and alert-delivery tests | Monthly |
| WZ-10 | Recoverability | Configuration backup and isolated snapshot restore | Quarterly |

Map these local controls to the organization's chosen NIST, ISO, CIS, regulatory, contractual, and privacy requirements with versioned evidence and qualified review.
